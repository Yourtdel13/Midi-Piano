# v3.20 正式版

首个正式版：MIDI / MusicXML(MXL) 播放、同步乐谱、自由弹奏、粒子与氛围特效。

## 主要功能
- MIDI 解析（format 0/1、tempo、CC64/CC7/CC11、多轨）
- MusicXML / MXL 乐谱同步：反复、房子、D.C./D.S./Segno/Coda/Fine、8va/8vb、
  延音线/圆滑线、倚音、连音、力度记号与渐强渐弱
- 88 键瀑布流、9 色泛光、5 种形状、渐变/左右手配色
- 水花/火花/火焰/樱花/枫叶/赛博/星尘命中特效，多种背景氛围与密度
- FluidR3_GM 钢琴采样、延音踏板混响、强弱曲线
- 自由弹奏：点键发声、双指缩放、上下拉伸、刮奏
- 开始界面、四分区设置、性能模式、FPS 调试

## 修复的 Bug
- 延音踏板不显示、无效果；无 CC64 的 MIDI 自动补延音
- C4 以下音量偏小；改用原声大钢琴采样
- 弹奏卡顿、短音符掉帧；乐谱与瀑布流不同步
- 刮奏/缩放断滑，刮奏最多经过三个键（BUG#001）
- 音符泛光显示成透明矩形框
- 导入 MIDI 后曲名显示错误
- 低音轨高于 C4 的音符仍用右手配色
- 低音谱连桁断裂、和弦符干方向不一致、G3 以上被横杆遮挡
- 十六分/三十二分符杆与横梁不明显
- 加线数量翻倍、8va 显示成 8vb、8va 影响低音谱
- 倚音未到竖杆就变蓝
- 琶音记号长度固定、断奏作用于整个和弦
- 力度记号 mf/f/ff 全显示为 fff
- 渐强/渐弱线随力度记号消失、位置压在低音谱上
- To Coda 提前触发、D.S. 不回 Segno、谱面不跟随反复
- Segno / Fine 记号不显示
- 自由弹奏提示没有关闭按钮；横向滑动导致钢琴与音符条错位
- 缩放可以超过 100%；部分机型播放黑屏/白屏
- 控制条遮挡键盘、顶栏无法隐藏
